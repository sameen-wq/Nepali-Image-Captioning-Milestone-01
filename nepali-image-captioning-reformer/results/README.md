# Results and interpretation

- `smoke_test_random_weights/metrics.json` is generated by the packaged code on 2026-11-12 using a **randomly initialized** network. It validates execution, dimensions, finiteness and repeatability **only**. It must not be cited as pretrained-feature effectiveness, image recognition or caption performance.
- `pretrained_resnet18/metrics.json` will be created when the pretrained experiment is run. It is not included until the pretrained weights are actually downloaded and executed.
- `embeddings.npz` saves numerical vectors. Each row corresponds to a label in the same archive. It is not a language representation.
- Similarity on two demonstration photos (and one mirrored version) is **not** a rigorous benchmark. A validated dataset, appropriate baselines and repeat tests are needed.

Notebook users should reproduce the pretrained run and commit the verified results and environment metadata when permitted by the supervisor.
